# リダ実モデルのBlender・Unity・UE表示例

© 2026 Lida · 出典：[LidaAngelToon](https://github.com/Lida-V/LidaAngelToon)。全身と顔の3列画像は、各環境で実際に描画したものです。公開PNGの余白にも作者と出典URLを表示しています。

## 何を比較しているか

| 列 | 実際に使った環境と材質 | 位置づけ |
|---|---|---|
| 左 | Blender 5.2.1 LTS / EEVEE、制作材質`LidaSoftToon` | Unity・UE実装が目指した開発基準。配布Blenderアドオンの適用例ではない |
| 中央 | Unity 6000.6.0f1 / URP 17.6、LidaAngelToon 0.1.0 | Linear、Forward+、Direct3D 11、Windowsの実表示 |
| 右 | Unreal Engine 5.8、LidaAngelToon 0.1.0 | Windowsの実表示。Unlitで独自のトゥーン計算を行い、落ち影を受けない |

Blenderモデルから同じ制作外観をエンジン用FBXへ書き出した系統です。UnityとUEは同じFBXを使い、全身・顔それぞれでカメラの構図と主光を揃えました。元のBlenderファイルとFBXは同一形式・同一ファイルではありません。

ブルームなし、トーン曲線なし、輪郭線は[決まりB](../OUTLINE-RULE-B.md)。UEのTone Curve Amount=0は、トーンマッパー全処理の停止を意味しません。露出・色設定の方法は[色とトーンマップ](../COLOR-AND-TONEMAP.md)を参照してください。

## 画像

- [全身3列](engine-model-gallery.png)：2572×1524。髪・肌・多段衣装・翼・金属装飾の表示例。
- [顔3列](engine-face-comparison.png)：2512×1324。肌の明暗、目、髪、装飾を近くから確認する例。

元の6パネルを拡大縮小・色補正・描き足しせず、説明と出典の台紙へ配置しています。保存したPNGを読み直し、各パネルのRGB画素が元描画と同一であることを確認しました。撮影情報・ローカルパス等の付随メタデータは含めていません。

BlenderとUEは既存の検証レンダー、Unityは同じ固定撮影処理で復元したPNGを使いました。Unityの描画では既存のモデル・パッケージ・描画コード・材質入力を変更していないことを確認し、シーンを保存していません。

## 作例と配布物の違い

Unity・UEの材質は、モデル固有の基本色、テクスチャ、マスク、MatCap、パラメータを設定した例です。インストールや初期値だけでこの外観を自動再現するものではありません。試験実装と配布実装は、実装ロジックが同じであることを照合しています（ライセンス・ファイル名を指すコメント、文書、パッケージの名前・作者・ライセンス欄、パッケージのフォルダ名の差は別に記録）。

配布Blenderアドオンと開発基準材質は別実装です。アドオンの実適用によるプリセットと入力比較は[原始図形の画像条件](README.md)を参照してください。アドオンとUnity・UE共通コアの数値一致は未検証です。
