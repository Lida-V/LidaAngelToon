# 0.1.0の確認範囲

## Blenderで実行した確認

Blender 5.2.1 LTS、Windows、EEVEE。検証用に新規作成した球と立方体のみを使い、モデル・FBX・VRM・参考モーションは読み込んでいません。

| 確認 | 結果 |
|---|---|
| 10プリセットのノード生成 | 成功 |
| 布・髪・金属の適用と原始図形の描画 | 成功、描画画像を目視確認 |
| 基本色の元リンク保持 | 成功 |
| メッシュ座標の保持 | 適用・再適用・保存再読込で一致 |
| 元の出力への復帰と再適用 | 成功、ノードや輪郭線を重複追加しない |
| 任意のAlpha・AO属性入力 | ノード構築成功 |
| Sunのドライバー | 7本、無効なし |
| 自作画像の同梱 | 6枚をblendにpackし、保存再読込成功 |
| addon ZIPの導入 | 分離したscripts領域へ実際にインストールし、有効化→立方体へ適用→無効化に成功 |
| 手続き素材の再生成 | 同じ環境で6枚すべてバイト一致 |

## READMEの外観紹介

READMEに掲載するプリセット一覧と設定比較は、公開版0.1.0のノードを新規の原始図形へ適用して描画したものです。条件と変更した設定は[画像の説明](images/README.md)にまとめています。シェーダーの表示例であり、実キャラクターでの検証、物理的な材質、他のソフトでの再現を保証するものではありません。

## 配布ツール

15テスト中14成功、OS上のシンボリックリンク作成が許可されないため1件skip。ZIP内のシンボリックリンク拒否は別テストで成功しました。許可一覧の欠落・追加、FBX等の混入、版不一致、ZIPの改変・欠落・重複・追加、決定的なZIP生成を確認しています。

ソースZIPとaddon ZIPを作成し、収録一覧とファイルのSHA256を元ソースと照合します。GitHub ActionsにはWindows／Ubuntuの配布ツール検査を用意しています。実行結果は各コミットのActionsで確認してください。この文書だけで遠隔CIの成功を主張するものではありません。

## 残る確認

手動GUI操作、他OS・他のBlender版、複雑な独自材質、実キャラクターの全身動作、反転ハルの負荷、VRM／Unity／UEは、この配布版の検証対象に含めていません。AlphaとAOは入力経路の試験で、任意モデルの透明・接触品質を保証する結果ではありません。
