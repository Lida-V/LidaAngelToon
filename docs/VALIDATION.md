# 確認範囲

Blender アドオン 0.1.0 の確認と、リポジトリ 0.2.0 で足した確認です。

## Blenderで実行した確認（アドオン 0.1.0）

Blender 5.2.1 LTS、Windows、EEVEE。検証用に新規作成した球と立方体のみを使い、モデル・FBX・VRM・参考モーションは読み込んでいません。

| 確認 | 結果 |
|---|---|
| 10プリセットのノード生成 | 成功 |
| 布・髪・金属の適用と原始図形の描画 | 成功、描画画像を目視確認 |
| 基本色の元リンク保持 | 成功 |
| メッシュ座標の保持 | 適用・再適用・保存再読込で一致 |
| 元の出力への復帰と再適用 | 成功、ノードや輪郭線を重複追加しない |
| 任意のAlpha・AO属性入力 | ノード構築成功 |
| Sunのドライバー | 7本、無効なし |
| 自作画像の同梱 | 6枚をblendにpackし、保存再読込成功 |
| addon ZIPの導入 | 分離したscripts領域へ実際にインストールし、有効化→立方体へ適用→無効化に成功 |
| 手続き素材の再生成 | 同じ環境で6枚すべてバイト一致 |

## 配布ツール（0.1.0）

15テスト中14成功、OS上のシンボリックリンク作成が許可されないため1件skip。ZIP内のシンボリックリンク拒否は別テストで成功しました。許可一覧の欠落・追加、FBX等の混入、版不一致、ZIPの改変・欠落・重複・追加、決定的なZIP生成を確認しています。

ソースZIPとaddon ZIPを作成し、収録一覧とファイルのSHA256を元ソースと照合します。GitHub ActionsにはWindows／Ubuntuの配布ツール検査を用意しています。実行結果は各コミットのActionsで確認してください。この文書だけで遠隔CIの成功を主張するものではありません。

## 残る確認

手動GUI操作、他OS・他のBlender版、複雑な独自材質、実キャラクターの全身動作、反転ハルの負荷、VRMは、このアドオンの検証対象に含めていません。AlphaとAOは入力経路の試験で、任意モデルの透明・接触品質を保証する結果ではありません。Unity・UE 版の確認の範囲は [README](../README.md) の表を見てください。アドオンのノードグループと Unity・UE の共通の式の数値は比べていません。

## リポジトリ 0.2.0（Unity・UE 版をまとめた版）で足した確認

Windows で実行。アドオンのコード・画像・Blender のテストは 0.1.0 と同じバイトです。

| 確認 | 結果 |
|---|---|
| 単体テスト（配布ツール 18、リポジトリの中身 11） | 29件中28成功、ホストでシンボリックリンクを作れないため1件skip |
| 許可一覧の検査 | 99ファイル PASS |
| 配布ZIP 4つ（source・blender-addon・unity・unreal） | 作成し、各ZIPの収録一覧とSHA256が元ソースと一致 |
| 共通の式の3つの写し | 同じバイト |
| UE の Custom ノードの文 | core から作り直すとバイトまで同じ |
| blender-addon ZIPの導入 | Blender 5.2.1 LTS の分離したscripts領域へ入れ、有効化→立方体へ適用→無効化に成功 |
| 原始図形の描画 | 成功。0.1.0 の確認の描画と比べ、3画素だけ1/255の差（EEVEEの実行ごとの差） |

Unity・Unreal Engine 本体は、このまとめでは動かしていません。リポジトリの Unity・UE・core のファイルは、エンジンの試験で使ったものと比べて、頭のライセンス・著作権のコメント行、`package.json` の `author`・`license` の欄、説明書だけが違います（コードは同じ）。

上表は当初の99ファイル統合コピーでの検査です。公開向けのREADME画像と条件資料を追加した版でも、収録一覧・既存テスト・4種類のZIPを再確認します。実際の遠隔CIは対象コミットのActionsで確認してください。

## READMEの実描画資料

公開アドオン0.1.0の原始図形2枚は[画像条件](images/README.md)、リダ実モデルのBlender開発基準・Unity・UEの2枚は[実モデルの条件](images/engine-models.md)へ区別しています。Unity掲載PNGは同じ固定撮影処理で再取得し、既存入力のSHA保持と描画結果を確認しました。BlenderとUEは既存実描画を使用しています。今回新たにBlenderアドオンを制作モデルへ適用したという意味ではありません。
