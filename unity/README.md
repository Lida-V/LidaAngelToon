# LidaAngelToon for Unity (URP)

The package is `jp.lida.angeltoon/` (version 0.1.0). Manual: `jp.lida.angeltoon/Documentation~/LidaAngelToon.md`
(every property, passes, keywords, outline, cut-out, scene settings, presets).

## Requirements

Unity 6000.0 or later with URP 17 (`com.unity.render-pipelines.universal` 17.0.0+). Tested with Unity 6000.6.0f1,
URP 17.6, Linear colour space, Forward+, Direct3D 11 on Windows. Other graphics APIs and platforms are not tested.

## Install

- Copy `jp.lida.angeltoon` into `Packages/` of the project, or Package Manager > + > Add package from disk... and pick
  `jp.lida.angeltoon/package.json`.
- The `.meta` files are part of the package (they keep the asset GUIDs stable); copy them too.

## First material

1. Create a material, shader `LidaAngelToon/Toon`. Set Base Map (sRGB) and Base Color.
2. Mask (optional): import with sRGB off and without single-channel compression, assign "AngelToon Mask", turn on
   "Use Mask Texture". R occlusion (1 = open), G second layer, B outline area, A per material.
3. Light: the URP main light is the key light. For a fixed character light add `AngelToonGlobals`
   (Add Component > LidaAngelToon > AngelToon Globals) and turn on Override Key Light (the transform's forward is the
   direction the light travels). Ambient Mix / Additional Light Mix are 0 by default.
4. Outline: on by default (pixel rule B: Gain 1.5, Min 1 px, Max 2 px, natural width in mm). Turn it off per material
   with the "Outline" toggle.
5. Cut-out: Alpha Clip on, Cutoff, and Alpha To Coverage on (needs MSAA) for soft edges.
6. Translucent / painted shadow layer: `LidaAngelToon/Toon Transparent` (Multiply Layer for a layer that only darkens).

## Model import tips

- Hard-edge normals open gaps in the outline: select the model, Assets > LidaAngelToon > Outline Normals On Import
  (toggle), set Tangents to Calculate Mikk in the model import settings (the smoothed normal is stored in tangent
  space in UV3), re-import, then Outline Normal = "Smoothed Normal In UV3" in the materials.
- Thin double-sided parts (front and back at the same position) can get an unstable smoothed normal.
- With a humanoid rig, check the automatic bone mapping (for example the Jaw slot can pick a hair bone, Toes can stay
  empty) and load a Human Template (`.ht`) after Mapping > Clear if needed.

## Presets

Tools > LidaAngelToon > Create Materials From Preset... reads a JSON file of format `LidaAngelToon.preset/1`
(materials with their values in linear colour, textures with import settings, keywords, renderer assignments,
files to copy). Character data stays in the preset; no preset is included in this folder.

## Not included / limits

- No sample scene, no preset, no MatCap texture.
- The two `.shader` files were generated by an internal script (named in their header comment, not included). Their
  property lists and `UnityPerMaterial` layouts must stay identical (SRP Batcher): change both in the same way.
- Overlapping translucent layers inside one renderer can sort wrong; prefer cut-out where possible.
- The GPU time alone was not measured (tests ran without a window; see the main README for frame times).
- The package name `jp.lida.angeltoon` is a working name (decide it before publishing). `package.json`:
  author Lida, license `LicenseRef-Lida-Attribution-1.0`.
- The default values of the shader properties give a soft cloth look (layer A) and a soft skin look (layer B, `_L2_`).
